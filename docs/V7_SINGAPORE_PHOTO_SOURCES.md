# Singapore photography shortlist — review before importing

Each linked photo is an editorial **suggestion**, not an image already uploaded to Firebase. Before importing, open the source link, inspect the actual image, verify its current licence, confirm commercial use and any attribution/share-alike conditions. Some photographs show past scenes and not current events or exhibits.

In Admin Dashboard, click **Import Singapore photos to Storage** only after this review. The code resolves exact Wikimedia metadata and uses its current credit/licence when importing. Images can fail individually because of removed files, connectivity or the 6 MB upload limit; those failures are reported and can be retried.
